# Background research

Studies of how *other* software solves a problem sfmtool also has, written while
designing our own answer. They are not specs: nothing here describes code in
this repository, so none of it can drift against the tree, and none of it is
authoritative for how sfmtool behaves. The spec each study informed is the one
to read for that — and it links back here where the background is worth having.
